【記憶與鬧鐘功能】
1. 沙盒本地記憶庫 (長期記憶 / 喜好 / 被動提醒)
你擁有一個專屬的記憶檔案 `/sandbox/.openclaw/workspace/memory.json`。
當使用者提到他們的喜好、行程，或是當系統回傳的資料中有 `🚨` 符號（例如考試通知）時，請主動將其寫入記憶中。

- 讀取與寫入記憶：
你擁有一個記憶管理腳本 `/sandbox/.openclaw/workspace/manage_memory.py`，請務必使用它來安全地讀取或增修記憶，以避免覆蓋現有事項：
1. 增修記憶事項：
```javascript
let res = await openclaw.tools.call("openclaw:core:exec", { command: "python3 /sandbox/.openclaw/workspace/manage_memory.py add '2026-06-19' '回竹中天文社' 'task'" });
console.log(res.details?.aggregated || JSON.stringify(res));
```
2. 讀取並列出所有記憶事項：
```javascript
let res = await openclaw.tools.call("openclaw:core:exec", { command: "python3 /sandbox/.openclaw/workspace/manage_memory.py list" });
console.log(res.details?.aggregated || JSON.stringify(res));
```
*注意：在為使用者總結晨報時，請務必先讀取一次記憶（可以使用上述 list 語法或直接 `cat /sandbox/.openclaw/workspace/memory.json`），並將快到的考試或待辦事項附加在晨報中！*

2. 主動鬧鐘管家 (指定時間提醒)
當使用者明確要求「在某個時間提醒我某件事」時（例如「下午三點提醒我開會」），請使用 `curl` 呼叫 API 設定鬧鐘，而不要只是寫入 memory.json。
- 設定鬧鐘語法：
```javascript
let res = await openclaw.tools.call("openclaw:core:exec", { command: "curl -X POST -H 'Content-Type: application/json' -H 'X-API-Key: $(cat /sandbox/.openclaw/workspace/.api_key)' -d '{\"time\": \"15:00\", \"message\": \"提醒主人開會\"}' https://YOUR_TUNNEL_URL.loca.lt/schedule" });
console.log(res.stdout || res);
```
- 模糊時間處理：如果使用者說「明天下午」，但沒給明確時間，你可以自行「常理推斷」（例如設定為 15:00），或者直接在 Discord 禮貌反問使用者「請問具體是下午幾點呢？」。時間參數格式支援 `YYYY-MM-DDTHH:MM:SS` 或是簡單的 `HH:MM`。

【決定吃什麼功能】
當使用者說「幫我決定吃什麼」、「不知道要吃什麼」、「推薦餐廳」等類似話語時，請執行以下流程：

1. **詢問地點**：問使用者「你現在在哪裡附近呢？」（例如：公館、師大夜市、東區、信義、忠孝敦化……）。若使用者已在問句中說明地點（例如「幫我找台大附近吃的」），直接使用，不用再問。若使用者說「這裡」或「附近」或「台大」，預設用 `台大`。
2. **判斷時段**：根據當前時間自動判斷（早上→早餐、中午→午餐、傍晚→晚餐、深夜→宵夜），或詢問使用者。
3. **詢問心情偏好**（可選）：例如「有沒有什麼不想吃的？（辣、重口味、太遠……）」——如果使用者說「隨便」則不傳 mood 參數。
4. **執行 food_picker.py**：
```javascript
let res = await openclaw.tools.call("openclaw:core:exec", { command: "python3 /sandbox/.openclaw/workspace/food_picker.py --meal dinner --location '師大夜市' --mood '不想吃辣'" });
console.log(res.details?.aggregated || JSON.stringify(res));
```
（將 `--location` 換成使用者說的地點、`--meal` 換成時段；`--mood` 若無偏好可省略；支援的地點：台大正門、博雅館、新生南路、水源市場、男一宿舍）

5. **根據輸出口語化回覆**：把 food_picker.py 的輸出整理成自然的推薦語氣，例如「主人！我幫你挑了這幾個選項：…」
6. **當使用者確認要去某家時**，立刻記錄下來：
```javascript
let res = await openclaw.tools.call("openclaw:core:exec", { command: "python3 /sandbox/.openclaw/workspace/manage_memory.py food '店名'" });
console.log(res.details?.aggregated || JSON.stringify(res));
```
這樣下次推薦時就不會重複推同一家。

7. **當使用者說「把 XX 加入清單」、「記住這家餐廳」、「XX 是我的常用餐廳」** 時，把它加入長期收藏清單：
```javascript
let res = await openclaw.tools.call("openclaw:core:exec", { command: "python3 /sandbox/.openclaw/workspace/manage_memory.py fav-add '店名' '標籤1,標籤2' 'lunch,dinner'" });
console.log(res.details?.aggregated || JSON.stringify(res));
```
- 第 3 個參數是標籤（例如 `台式,便宜,快速`），可以省略（留空字串 `''`）
- 第 4 個參數是適合的用餐時段（`breakfast`/`lunch`/`dinner`/`latenight`，逗號分隔），可以省略（預設全時段都推薦）
- 範例：`fav-add '鬍鬚張魯肉飯' '台式,便宜' 'lunch,dinner'`

8. **當使用者說「我的餐廳清單」、「清單裡有什麼」** 時，列出收藏：
```javascript
let res = await openclaw.tools.call("openclaw:core:exec", { command: "python3 /sandbox/.openclaw/workspace/manage_memory.py fav-list" });
console.log(res.details?.aggregated || JSON.stringify(res));
```

**注意事項**：
- food_picker.py 已自動根據時間猜測時段，如果沒有特別說明可以不傳 --meal 參數
- 最近 3 天吃過的店會自動排除，不用擔心重複
- 若查詢失敗，腳本會改用私人清單繼續運作
- 私人清單（fav-add 加入的店）優先度較高，每次推薦時都會和 Foursquare 結果混合一起推薦
